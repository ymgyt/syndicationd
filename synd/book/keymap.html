Keymap

A key binding assigns a command to a key or a sequence of keys. A layer is a group of bindings. In the Entries tab, j moves to the next item using the list layer, and Space opens the reader using the entries layer.

Screen or promptActive layers, highest priority first
Entries tabfilter → entries → list → tabs → global → app
Feeds tabfilter → feeds → list → tabs → global → app
Typing a searchsearch-prompt just before filter in the current tab
Choosing categoriescategory-filter just before filter in the current tab
Article readerreader → global → app
Subscribe or editsubscribe → text-input → app
Unsubscribe confirmationunsubscribe-popup → app
Login screenlogin → global → app

When two layers handle the same key, the one on the left takes priority. In the Entries list, q quits (global). In the article reader, q closes the article (reader).

Custom Key Bindings

To read the selected article with o in the Entries tab, add this to your configuration file.

[keys.entries]
keymap = [
  { on = "o", command = "entries.read" },
]

Restart synd and select an entry. Both o and Space now open the reader. Reusing a key in the same layer replaces its default binding. To disable Space, add { on = "space", command = "no_op" } to the same array.

To bind another action, put its layer name after keys. and its command name in command. You can find both under Default Key Bindings. An optional desc supplies the label when the binding appears in the status line.

Default Key Bindings

Use the key names below in on. For a sequence such as g g, write on = ["g", "g"]. The prefixes C-, S-, and A- stand for Ctrl, Shift, and Alt.

Entries and Feeds

In Feeds, press a to subscribe or e to edit the selected subscription. Use Tab and Shift-Tab to move between fields. A new subscription defaults to polling every 24h. Editing opens the saved poll interval and labels, including category. Choose Remove beside a label to delete it and Save to apply the changes. Press Esc to cancel.

synd assigns the keys for search-prompt and category-filter. While searching, use Backspace to delete the previous character. While choosing categories, press the shortcut beside a category to toggle it, + to select all categories, or - to clear the selection.
